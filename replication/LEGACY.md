# Replication: What Counts as a Step?
Run python3 audit.py in this directory (Python 3.9+). The frozen data need no network connection, model, or credentials. The script rewrites results/rescored.csv, summary.csv and contrasts.csv. All confidence intervals are paired, question-clustered percentile intervals in percentage points. chance in summary.csv is an expected number of *additional* correct calls, not total accuracy. adjacent counts only misses exactly one record away.

data/indices.csv has one row per paired trace, including the original event offset, the four frozen predictions, the pilot flag, the per-message prefix cap, the runtime prompt count and local call digest. data/event_groups.csv is the complete map for 184 traces; only the 180 cohort IDs contribute to the primary tables. The remaining cases can be inspected in data/full_archive_scores.csv, which covers the three methods with full-archive rows. Filenames are unique within subset. Subsets are not independent across question IDs.

Primary sources:
- https://github.com/ag2ai/Agents_Failure_Attribution/tree/b2bae5c5b06d681d04ea5e9b63b7a30525c04925
- https://github.com/Mr-Capybara/CHIEF/tree/2b47170c41913c8bdea34397f7d52c65360dcef9
- source_manifest.json identifies the CHIEF archive path and blob hash. Download the file ending in 0519_1754.jsonl for this study. Correctness flags in analysis use benchmark reference indices. A missing CHIEF output was retained as a miss in the 184-trace sensitivity table. We do not redistribute the full third-party prediction archive or log text.

For a full rebuild rather than rescoring: create a clean work directory, check out the pinned benchmark as attribution-source, copy workflow as its sibling (the directory name workflow may be kept), and place the pinned 0519_1754.jsonl in workflow/sources under its original basename. Run python3 workflow/analyze.py and python3 workflow/sensitivity.py. The former reconstructs event groups and the Bayes and cue predictions. With a local Ollama service and qwen3:14b installed, run python3 workflow/local/full_audit.py. It reads workflow/paired_scores.csv and event_groups.csv and writes full_predictions.csv. Join the latter to paired_scores.csv by subset and file. For the controlled workflow run python3 workflow/local/run.py and python3 workflow/local/summarize.py. Retaining calls/ reuses identical model responses. Exact model regeneration may vary by runtime or hardware. The frozen event indices make numerical verification independent of such variation.

data/controlled_pairs/ has both branches, targets, known sites and diagnosis for all 12 tasks; data/controlled_scores.csv stores the two scores for each diagnoser. The order tasks are generated examples. They must not be pooled with the public failure cohort. procedures/ contains the dated-in-context exploratory protocols. The matched-cohort inference extension, global question clustering, and boundary-placement control were added after the pilot.
