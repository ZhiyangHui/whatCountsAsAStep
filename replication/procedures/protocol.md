# 探索性分析约定（查看重评分结果前写定）
数据是 Who&When 原版 184 条失败轨迹。以原始 history 下标（从 0 开始）作最细评测单位，不把一句话再拆成词。人工步骤与 CHIEF 快照标签不一致的轨迹单列，预测缺失计错，另报全量敏感性分析。标注所指的动作以步骤号为准，单独审计角色字段，不按角色更正标签。
三种粒度：(1) 每条原始记录；(2) 同一发言主体的连续记录为一组，Orchestrator 的 thought、dispatch、termination 视为同一主体；(3) 每次明确派工与下一条相应执行者回复为一组，或一次专家动作与紧随的 Computer_terminal 工具记录为一组，其余单列。同一对话无序号重排，禁止根据答案、预测或其距离划组。后两种为根据日志结构定义的研究评分规则，未确认为任何产品的实际默认显示方式。
方法：已发布 CHIEF/Qwen 单次逐例输出；两个本地可复算基线：首个显式失败词线索（无命中取首个非 human 记录）；分数据子集、按问题 ID 留组交叉拟合的消息文本和发言人朴素贝叶斯（每条轨迹中对数似然比最大的记录）。同一方法每条轨迹只预测一次，各粒度均用相同下标。各方法以分组命中计分，比较严格排名反转与平局；另给按子集和问题聚类的配对不确定性。禁止为了找到翻转而改规则。本实验估计评分敏感性，不估计模型读取不同格式后的行为变化，也不把任务失败等同安全事件。
